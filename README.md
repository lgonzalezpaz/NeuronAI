# NeuronAI

[![DOI](https://zenodo.org/badge/1377715284.svg)](https://doi.org/10.5281/zenodo.22851741)

A biophysical neural-mass model of EEG dynamics for personalized pharmacological
simulation in autism spectrum disorder.

---

## Description

NeuronAI combines an extended biophysical neural-mass model of EEG dynamics
with an artificial intelligence system. Given a pathological EEG (e.g., from
an autistic subject) and a reference EEG (e.g., from typically-developing
subjects), it predicts personalized receptor agonist/inhibitor modulations
that are predicted to move the subject's spectral profile toward the reference.

The platform is a hypothesis-generating tool. Outputs are model-based
predictions, not validated clinical prescriptions.

The model integrates:

- Differentiated glutamatergic receptors (AMPA, NMDA NR2A, NMDA NR2B).
- Neuromodulatory systems (dopamine, serotonin, norepinephrine).
- Kuramoto order parameter and Phase Locking Value (PLV) as biomarkers for
  optimization.

---

## Key features

- **Digital twin of an EEG recording** based on a three-population neural-mass
  model in the Jansen–Rit / Wendling family.
- **AI-predicted optimal modulations**: a neural network trained on synthetic
  data generated by the model itself.
- **Subject-anchored response projection**: predictions are evaluated against
  the subject's real spectrum, not against a simulated surrogate.
- **Combinatorial search** over 129 modulation combinations (single, pairs,
  triples) with greedy assembly of multi-target interventions.
- **Bootstrap confidence intervals** and a **measured response-noise floor**.
- **Seven-level validation protocol** (static analysis, unit testing,
  property-based testing, coverage, contracts, mutation testing, and
  fuzz testing).

## Version history

### v1.0.2 (current)

Introduces four targeted improvements over v1.0.1. All original functionality
is preserved.

**Change 1 — Scale-aligned spectrogram.**
The `spectrogram_db` function now standardizes each signal to unit variance
before computing the spectrogram. This preserves spectral shape (the feature
relevant for the distance) and removes the arbitrary absolute offset between
real EEG (Volts) and model output (mV). All downstream callers benefit
automatically without API change.

**Change 2 — Model base anchored to the TD reference.**
Three handlers (`on_optimize_click`, `on_simulate_click`, `on_apply_ai_click`)
now use the TD-fitted parameters (`td_params_fitted_global`) as the model
base instead of fitting the model to the subject. This mirrors the stable-base
approach of Neuron ASD. When a subject's spectrum falls outside the model's
repertoire, the platform reports "no effective modulation" rather than
forcing a spurious one.

**Change 3 — Line-noise cleanup (50 + 60 Hz).**
A new **CLEAN LINE NOISE** button applies a strong IIR notch (Q = 10, two
passes) at both 50 and 60 Hz, symmetrically to subject and TD. The tool
reports the ratio before and after, so the user can verify that the
interference has been removed.

**Change 4 — Response projection.**
The `Improvement (%)` column in the prediction table now measures how much
the subject's real spectrum approaches the TD reference, not how much the
model changes. Modulations are evaluated over a subject-anchored ensemble
of five operating points, and each candidate carries a confidence (fraction
of the ensemble with positive gain) and an effective/no flag based on a
measured response-noise floor.

### v1.0.1

First public release with the neural-mass model, AI predictor,
combinatorial search, and manual modulation mode.
